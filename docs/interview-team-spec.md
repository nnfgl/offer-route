# 成员 D：文字与语音模拟面试

对应 Issue #4。负责人保持为当前指定组员；本次调整任务范围，功能尚未实现。

## 目标与范围

用户可以通过打字或说话完成同一次模拟面试，面试官问题可朗读，
两种输入共享岗位背景、会话轮次、追问和最终复盘。
首版按“提问→回答→确认提交→追问”的轮次进行。

### 文字模式

- 根据目标岗位及实际经历提问，支持有限轮次追问、结束面试和复盘。
- 用户可直接打字回答；反馈保留回答依据，薄弱点可交给训练模块。

### 语音模式

- 用户主动开启麦克风，支持开始、停止、取消录音和可见录音状态。
- 录音前说明转写用途；首版单段最长 60 秒、上传上限 8 MB，服务端复核大小、类型和时长。
- 语音识别后显示转写文字，允许编辑；用户确认后才提交给面试 Agent。
- 面试官问题支持语音朗读和停止播放；录音时避免同时播放问题，防止回声进入转写。
- 同一会话可切换文字/语音模式，保留已有问题、回答和轮次。
- 麦克风权限被拒、设备不支持、空录音、识别或播放失败时，给出提示并保留文字操作入口。
- 默认持久保存确认后的文字和必要元数据；原始录音用于本次转写，及时释放或清理临时文件。

## 实现与接口协作

- 面试 Agent 统一接收确认后的文本，复用 AgentRequest / AgentResult；语音不单独维护一套评分逻辑。
- 语音识别（STT）与语音合成（TTS）通过适配层接入，具体服务由 D 评估并在 Issue 中记录。
- DeepSeek 负责文字提问与复盘，语音能力由单独的适配层提供。
- 记录输入方式、轮次与确认后的回答，恢复会话时可以重现文字面试过程。
- 新增 API 统一在 `/api/v1`，复用当前用户、CSRF、错误格式和用户数据归属校验。
- 如需新增语音服务密钥，只放后端环境变量，补 `.env.example` 空值说明，不提交真实密钥。
- 配套完成 `frontend/src/features/agents/interview` 页面、后端接口与测试；共享协议和数据库迁移先在 Issue 中说明。
