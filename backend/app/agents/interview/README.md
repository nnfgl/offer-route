# 模拟面试 Agent

负责人 D。首版可独立完成三轮文字面试，支持历史记录、规则复盘与待训练项。

新增实时语音入口，采用浏览器 WebRTC 直连百炼、后端鉴权代理和转写持久化。
允许插话打断；面试结束并冻结转写后，才异步生成模型复盘。

- `voice_schemas.py`：语音会话、转写与结构化复盘协议。
- `voice_provider.py`：供应商适配（SDP 交换、会话配置和有原文校验的复盘）。
- `voice_router.py`：独立语音 API、归属/CSRF、结束与复盘任务重试。

配置与验收边界见 [实时语音文档](../../../../docs/voice-interview.md)。

- `schemas.py`：创建、回答与会话的具体协议。
- `router.py`：持久化、登录态、CSRF、归属检查与轮次冲突保护。
- `service.py`：基于经历和上一轮回答的追问，以及带原文依据的规则反馈。

无需外部模型或其他业务模块。评分只检测中文表达线索，不验证技术正确性。
待训练项存于面试复盘中，公共能力档案完成后再联调回写。
完整接口、手动验收和协作说明见 [模块文档](../../../../docs/interview.md)。
